# DSTA_NULL - Crisis Watch
## - Our Tagline: From the unexpected to the unthinkable, Crisis Watch has your back -

Crisis Watch is a comprehensive emergency response and reporting application designed to help users stay informed and take action during various crisis situations. The app provides real-time news, emergency checklists, reporting tools, and guides for different types of emergencies such as fires, floods, medical incidents, natural disasters, pandemics, terrorism, and more.

## - Unique Selling Point:
Our integrated app  empowers individuals and families to stay safe and prepared for any type of emergency, offering personalised emergency plans, checklists, real-time alerts, and critical resources offline, ensuring peace of mind during times of emergency.

## Features

- **Real-Time News:** Stay updated with the latest news and alerts about ongoing crises.
- **Emergency Checklists:** Access tailored checklists for different crisis scenarios (fire, flood, medical, etc.).
- **Incident Reporting:** Report incidents such as accidents, fires, floods, medical emergencies, and more directly through the app.
- **Guides & Resources:** Get step-by-step guides on how to respond to various emergencies.
- **Emergency Contacts:** Quickly access and manage emergency contact information.
- **Notifications:** Receive timely notifications about nearby incidents and important updates.
- **User Reports:** View and manage your submitted reports.

## Tech Stack

- **React Native / Expo:** Cross-platform mobile app development framework for building native apps using React.
- **JavaScript:** Main programming language for app logic and UI.

## Project Structure

- `App.js` / `index.js`: Main entry points for the application.
- `app/`: Contains all main screens and features, including checklists, reporting forms, news, guides, and more.
- `components/`: Reusable UI components such as the bottom navigation bar.
- `hooks/`: Custom React hooks for app functionality.
- `assets/`: Images, icons, and other static assets.

## Getting Started

### Prerequisites
- Node.js (v14 or above recommended)
- npm or yarn

### Installation
1. Clone the repository:
	```bash / terminal
	git clone <repository-url>
	cd crisis-watch
	```
2. Install dependencies:
	```bash / terminal
	npm install
	# or
	yarn install
	```

### Running the App
To start the development server:
```bash / terminal
npm start
# or
yarn start
```

### Building for Production
To build the app for production:
```bash / terminal
npm run build
# or
yarn build
```
